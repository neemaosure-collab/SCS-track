# Cloud Glossary

Term       Defination
Region -A region is a geographical area where AWS has data centers that provide cloud services
 Availability zone -is a separate location within a region that helps keep cloud services running.
Console - is a website where users access and manage AWS cloud services.
IAM -is a service that controls who can access AWS resources and what they can do.
User -is an identity created in AWS to allow a person or application to access resources.
Group -is a collection of IAM users who share similar permissions.
Policy -a set of rules that decides what actions a user can perform in AWS.
Instance-a virtual computer running in the cloud that can perform different tasks.
Bucket-is a container in Amazon S3 used to store files and other data.
Security group -is a virtual firewall that controls incoming and outgoing traffic for cloud resources.
Key pair -A key pair contains a public key and a private key used to securely connect to an EC2 instance.
SSH-is a secure method of connecting to and controlling another computer over a network.
